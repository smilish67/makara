# 마카라 플라네타리움

에이전트에게 일을 맡긴 뒤, 어떤 요청에서 조사가 시작됐고 어느 턴에서 구현과 수정에 토큰을 많이 썼는지 돌아보는 로컬 대시보드입니다. 코딩·조사·기획을 같은 방식으로 기록합니다. Makara 위키와 Honcho는 플라네타리움을 설치하기 위한 선행 조건이 아닙니다.

## 설치

Docker와 Docker Compose가 작동하는 Linux 또는 WSL에서 이 저장소를 내려받고 실행하세요. 호스트 설치 프로그램에는 Python 3가 필요합니다.

```sh
git clone https://github.com/smilish67/makara.git
cd makara
python3 planetarium/install.py
```

[로컬 대시보드 열기](http://localhost:18768)

첫 실행은 현재 사용자의 지원되는 과거 기록을 색인합니다. 이후 스캔이 끝날 때마다 20초 뒤 다시 확인합니다. PC를 껐다 켜면 Docker가 시작된 뒤 자동으로 재개하며, 중지 중 남은 기록도 다음 스캔에서 읽습니다. Windows에서는 Docker Desktop의 로그인 시 시작 설정이 여기에 영향을 줍니다. 새 클라이언트를 설치하거나 수집 제외 경로를 바꾸면 설치 명령을 다시 실행하세요. 기존 작업 이름과 인덱스를 재사용합니다.

## 화면에서 읽기

1. **세션**에서 에이전트·프로젝트·작업 이름으로 검색합니다. 요청, 도구 이벤트, 모델 호출, 응답을 타임라인에서 확인하고, 특정 턴이나 이벤트 종류로 좁힐 수 있습니다.
2. **작업별 사용량**에는 작업 디렉터리별 합계가 바로 나타납니다. 예를 들어 Codex에서 조사하고 OpenCode에서 시안을 만들었다면 두 세션에 같은 작업 이름을 입력하세요. 한 세션 안에서 일이 바뀌면 해당 턴만 따로 지정할 수 있습니다.
3. 상위 세션에 지정한 작업 이름은 연결된 하위 세션에 적용됩니다. 턴에 직접 지정한 이름이 우선합니다. 호스트가 연결 식별자를 제공하지 않은 앱 간 인계는 직접 묶습니다.
4. 오른쪽 위 수집 상태에서 호스트별 입력 파일 수, 오류와 마지막 확인 시각을 확인합니다. OpenCode 한 개 파일은 여러 세션을 담은 DB 하나를 뜻합니다.

## 범위와 토큰 읽는 법

| 호스트 | 로컬 입력 | 사용량 |
|---|---|---|
| Codex | 기본 sessions·archived_sessions 아래 rollout JSONL 및 Zstandard 압축 파일 | 응답별 사용량 우선. 같은 턴에 응답별 기록이 없으면 누적 카운터 차이를 사용 |
| Claude Code | 기본 projects 아래 세션·하위 에이전트 JSONL | 같은 응답 ID의 중복 기록을 한 번 집계. 입력·출력·캐시 생성·읽기 합산 |
| OpenCode 2 | 기본 데이터 디렉터리의 opencode.db, session_v2 및 session_message 테이블 | 제공된 총량 우선. 없으면 입력·출력·추론·캐시 읽기·쓰기를 합산 |

토큰은 호스트가 제공한 분류와 수치를 따릅니다. Codex의 캐시·추론 수치는 각각 입력·출력의 일부일 수 있습니다. 도구는 호출 전후의 사건으로 보이며 토큰은 모델 호출과 턴에 귀속됩니다. 전체 합계에는 측정된 호출만 들어가므로 구독 잔량이나 청구 금액으로 환산할 수 없습니다. 로컬 기록을 제공하지 않는 일반 ChatGPT 대화, 다른 PC의 작업, 앱에 기록되지 않은 동작은 이 화면에 나타나지 않습니다.

## 데이터와 운영

현재 사용자의 기본 세션 저장소를 읽기 전용으로 연결합니다. WSL에서 Windows 사용자 폴더를 찾을 수 있으면 두 환경을 함께 수집합니다. 설치 시 Makara capture.json의 excluded_paths를 가져옵니다. 로컬 작업 전반을 관측하며, Makara 대화 훅의 프로젝트 허용 목록과 독립적으로 작동합니다. 작업 디렉터리와 식별자, 시각, 모델, 토큰, 도구 이름·상태, 짧은 요청·응답 발췌를 저장합니다. 모델 내부 추론 본문·첨부·도구 인수와 출력 원문은 수집 대상에서 제외합니다. 발췌에서 알려진 자격증명 패턴을 가리지만 자유 서술에는 사적인 내용이 남을 수 있습니다.

서비스는 루프백 주소에서만 열립니다. 수집과 표시는 LLM·GPU나 외부 관측 서비스 호출 없이 동작합니다. 로컬 색인·작업 이름·설치 구성은 기본적으로 ~/.local/share/makara/planetarium/ 아래에 있습니다. MAKARA_HOME을 설정하면 그 위치 아래에 생성합니다. 설치 명령을 다시 실행하면 소스에서 이미지를 재빌드합니다.

```sh
docker compose -f ~/.local/share/makara/planetarium/compose.json stop
docker compose -f ~/.local/share/makara/planetarium/compose.json up -d
```

원본이 삭제되면 정상 연결된 전체 스캔 뒤 색인에서도 사라집니다. 백그라운드 수집을 중지하려면 위의 stop 명령을 사용하세요.
